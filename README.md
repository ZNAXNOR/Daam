# Daam
> Open-source price intelligence and fake discount detector.

Daam is a community-driven, zero-bloat browser tool that reveals whether an e-commerce sale discount is authentic or an artificial price hike.

## Project Pillars
- **Zero Bloat:** Minimal Material Design 3 surface, zero intrusive popups.
- **Privacy First:** No login required, zero personal browsing tracking.
- **Open Data:** Completely open-source price histories powered by community browsing.

## Tech Stack
- **Extension:** WXT + Manifest V3 + TypeScript
- **Backend:** Hono / Next.js
- **Database:** PostgreSQL via Drizzle ORM
